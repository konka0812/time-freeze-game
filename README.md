# 你不动，时间就停

▶ **在线试玩**：<https://konka0812.github.io/time-freeze-game/>

Superhot 式时间机制网页游戏 —— **你站着不动，全世界冻结；你一动，子弹、敌人全部苏醒。**

## 怎么玩

双击 `index.html` 直接玩（或起个本地服务器：`python -m http.server 8931 --directory time-freeze-game`）

| 按键 | 功能 |
| --- | --- |
| WASD / 方向键 | 移动（移动 = 时间流动） |
| 鼠标 | 瞄准（不加速时间） |
| 左键 | 开枪（短暂推动时间） |
| R | 换弹（1.1 秒，期间世界缓慢流动，危险！） |
| 空格 | 冲刺闪避（0.24 秒无敌帧，1.5 秒冷却，手机端为右侧按钮） |
| Q | 切换特殊武器（空投拾取，限时） |
| V / [ ] | 震动开关 / 音量（自动保存） |
| P / M | 暂停 / 静音 |

## 规则细节

- **生命 5 点**：受击掉血并短暂无敌；每波开始自动回满，BOSS 击破额外回 1 点
- **命中率**：发射/命中实时统计，结算页可见
- **武器箱空投**：四系武器各 25% 随机掉落（霰弹/微冲/磁轨/蜂群），10 秒时效，Q 切换
- **凝神**：静止蓄力 1.2 秒，下一发子弹**穿透 + 双倍伤害**——蹲不蹲点，是新手和高手的分界线
- **掩体**：每局随机生成、可被摧毁，挡子弹也挡激光
- **场景轮换**：每波随机切换战场——标准 / 雷雨（雨幕与子弹同冻结）/ 熔池（灼烧双方面的地面威胁）/ 迷雾（雾中敌人隐身）/ 低重力（子弹减速、身法加速）
- **凝神**：静止蓄力 1.2 秒，下一发子弹**穿透 + 双倍伤害**——蹲不蹲点，是新手和高手的分界线
- **掩体**：每局随机生成、可被摧毁，挡子弹也挡激光
- **擦弹**：子弹贴身 46px 内飞过 +30 分，显示「险!」
- **连击**：连续击杀翻倍计分，最高 ×5；站着不动太久会断连
- **敌人七种 + BOSS**：枪手 / 突进者 / 狙击手（激光锁定，掩体可挡）/ 布雷者（磐雷引信也遵守时间冻结——静止反而能安全穿雷区）/ 重装兵 / **回响者**（你 1.2 秒前的残影，重演你的走位并向你开枪）—— 每 5 波 **BOSS「红晶守卫」**：150 HP，螺旋弹幕 + 扇形连发 + 召唤援军 + **时锁冲击**（强制世界流动 2.6 秒）
- **场地掩体**：4 块黑曜石挡子弹也挡激光，攻防核心
- **道具**（每 3 波轮换）：⏱ 缓时怀表 / 🛡 护盾点数（BOSS 专属掉落，破盾冲击波清弹幕+击退）
- **冻结奖励**：所有子弹、碎片在时间静止时悬停空中，绕着弹幕走位是核心乐趣

## 素材 & 录制

- 全部美术素材由 gpt-image-2.5 生成（`assets/`），抠图脚本在 `tools/`
- `?demo` 后缀进入**自动演示模式**（自动走位/瞄准/开枪/死亡重开），挂机就能录抖音素材
- 封面图 `assets/cover.png` 可直接用作抖音封面
- 死亡页「战绩海报」一键导出 720×1280 分享图
- 连击 ×8 / ×16 自动捕获高光截图，死亡页可批量保存
- 本地 TOP5 排行榜 + 上局对比 + 触屏双摇杆 + **PWA 离线可玩**（手机“添加到主屏幕”即原生体验）
- `?codex` 直达图鉴，`?boss` 直达 BOSS 战
