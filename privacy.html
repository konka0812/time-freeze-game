《你不动，时间就停》隐私政策

更新日期：2026-10-12　适用版本：1.0.12 及以上

一、我们收集什么

本游戏不要求注册，不收集你的姓名、手机号、邮箱等个人身份信息。游戏进度与最高分记录保存在你设备的本地存储（localStorage）中，不会上传。

为了解游戏的设备激活量、活跃度与留存情况，我们接入了 TapTap 官方数据上报 SDK（TapSDK）。该 SDK 只在你点击「同意」后才会初始化，运行期间会收集并上传以下信息：

  • 设备信息与设备标识符：设备型号、操作系统版本、网络类型，以及可用于识别设备的标识符（如 Android ID、OAID，具体取决于设备与系统版本）
  • 应用信息：应用包名、版本号
  • 游戏内账号标识：本游戏没有登录体系。我们会在你同意后为本机生成一个随机匿名 ID 作为账号标识，用于统计活跃与留存。该 ID 与你的真实身份无关，卸载重装后会重新生成
  • 基础使用情况：启动、活跃时长等统计信息

二、这些信息用来做什么

仅用于设备激活、活跃、留存的统计分析，帮助我们判断各版本的表现并改进游戏。不用于广告投放；不出售、不共享给 TapTap 以外的任何第三方。

三、第三方 SDK

本游戏接入的是 TapTap 官方数据上报 SDK（TapSDK）。该 SDK 的数据处理规则以其官方隐私政策为准：
https://www.taptap.cn/doc/privacy-policy

本游戏不含任何广告 SDK，也不含任何内购或支付功能。

四、你的选择

首次启动游戏时会弹出同意提示。只有点击「同意」后才会初始化数据上报 SDK；选择「不同意」你依然可以完整游玩，游戏不会上传任何数据。

同意后如需撤回，可在系统设置中清除本应用数据，或卸载重装——下次启动会重新征求你的同意。

五、权限使用

振动权限（android.permission.VIBRATE）：用于受击时的振动反馈，可在系统设置中关闭。
网络权限（android.permission.INTERNET）与网络状态权限（android.permission.ACCESS_NETWORK_STATE）：仅供上述数据上报使用，后者只用来判断当前网络是否可用。本游戏为离线单机玩法，断网也能正常游玩。

六、未成年人

本游戏包含卡通风格的射击战斗内容，未满 14 周岁的用户建议在监护人指导下使用。如监护人不同意本政策，请在首次启动弹窗中选择「不同意」。
